# ERASKYE

ERASKYE — бұл заманауи толыққанды әлеуметтік желі веб-қосымшасы. Жоба пайдаланушылардың тіркелуіне, медиа жазбалар жариялауға, профильді басқаруға және әкімшілік панелін қолдануға арналған.

## Технологиялар стегі
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Node.js, Express
* **Басқару:** Git
